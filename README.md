# 小鹊课表

一个自用的 Android 课表客户端。数据来自学校正在使用的喜鹊儿教务服务的**公开接口**,
用来把课表、成绩、考试、通知放进一个自己顺手的界面里。

> **非官方客户端。** 与学校、与喜鹊儿服务的提供方均无任何隶属关系。
> 本项目不修改、不上传任何服务器端数据。

---

## 功能

| 模块 | 说明 |
|---|---|
| **日程** | 今天/明天要上什么;最近一节课加粗放大;绿条=已上完、黄条=未上;课后自动切到明天;可显示"这门课要带什么" |
| **课表** | 周视图网格、左右翻页、「回到本周」、课程详情 |
| **调休 / 换课** | 把某天的课挪到另一天;原位置灰显且不可点,调来的显示在目标日并标「调休」。日程、课表、提醒三处口径统一 |
| **导出** | 图片 PNG(整周一张图,可直接发群)、Excel、CSV、日历 .ics。走系统分享面板,**不需要任何存储权限** |
| **成绩 / 考试 / 通知 / 培养方案** | 课表之外的教务信息 |
| **上课提醒** | 课前提醒 + 每日摘要。提醒跟着调休走 |
| **锁屏「正在上课」** | 上课期间状态栏/锁屏显示当前课程与下课倒计时 |
| **上课悬浮窗** | 可选(默认关闭);开启后课中浮在其它应用上层,下课自动消失 |
| **AI 助手** | 可选,自填 API Key;对课表/成绩等做自然语言查询。**写操作只生成待确认的计划**,必须手动确认才会提交 |
| **选课监听** | 默认关闭;开启后低频轮询通知,随机间隔、夜间静默、最长 7 天 |

## 设计要点

- **凭据只在本机**:密码不落盘;token 等机密经 Android Keystore 的 AES-256-GCM 加密后保存。
  全项目没有任何遥测,App 不与除教务服务之外的任何服务器通信(自建 AI 助手为可选且需自己填 Key)。
- **不写服务器**:调休是纯本地的覆盖层,不会上传改学校的课表数据。
- **不做破坏性操作**:选课提交、退课这类不可逆动作在类型层面被隔离 ——
  它们**只产生待确认计划**,提交入口只对用户的确认动作开放。
- **没有存储权限**:导出走 `FileProvider` + 系统分享面板。

## 构建

需要 JDK 21 与 Android SDK(compileSdk 37 / minSdk 26)。

```bash
cd xiqueer-android
./gradlew :app:assembleDebug
```

### ⚠️ 公开的是源码,**不是可直接运行的完整客户端**

协议层里用于与服务器通信的**密钥常量没有包含在公开源码中**(见
`protocol/kotlin/src/main/kotlin/com/xiqueer/protocol/XqRsa.kt` 里的 `PUT-YOUR-*` 占位符)。

因此本仓库的代码**可以编译,但无法真正连上服务器** —— 相关常量需要你自己准备。
这样处理是有意的:那些常量不适合随源码一起分发。

同样地,签名配置从环境变量读取,仓库里不含任何密钥库:

```bash
export XQ_KEYSTORE=/path/to/release.jks
export XQ_KEYSTORE_PASSWORD=...
export XQ_KEY_ALIAS=...
export XQ_KEY_PASSWORD=...
```

没有配置时 release 构建会给出警告而不是失败,方便先跑通编译。

## 已知限制

- 成绩、考试等页面在**没有数据**时只跑过空状态渲染。
- 会话会过期。过期时服务端会拒绝请求,App 会在顶部提示「登录已过期」并给一键重新登录;后台发现过期会发一条通知。
- 课表的"第几周"由服务端按**服务器日期**计算,而日程页的"今天/明天"使用手机时间。把手机时间改乱会让日程显示错乱。
- 悬浮窗依赖「显示在其他应用上层」权限,部分系统会限制后台弹出此类窗口。
